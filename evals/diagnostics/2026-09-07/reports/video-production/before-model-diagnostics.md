# 可灵、Runway 与 Veo：商业视频应先选生产流程，再选模型

信息截止：2026 年 9 月 7 日。面向电商短视频与品牌内容负责人。

## 一、结论：三条试用路线，但没有一个可以直接包办成片

如果目标是把现有商品图片变成多组短镜头，可灵值得作为首轮候选；如果已有拍摄素材，主要工作是换背景、改光线、做版本变化，Runway 的编辑流程更切题；如果需要从图片或提示词生成带对白和环境声的场景，可以把 Veo 纳入与可灵的音画对照。这里比较的是需求与公开能力的匹配，不是已经测出的质量冠军。可灵也支持原生音频，Runway 还提供其他厂商模型，三者不能简单分成互斥的“模型品牌”。[可灵 3.0 指南](https://kling.ai/quickstart/klingai-video-3-model-user-guide)、[Runway 视频编辑](https://runway.com/product/ai-video-editor)、[Veo 3.1 功能文档](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/veo/3-1-generate)。

对电商团队，首先保住商品真实性：外形、包装文字、颜色和功能展示不应因生成而改变。对品牌团队，首先保住素材授权、保密义务和可修改性：不能因为一段演示漂亮，就把未发布产品、代言人素材或客户保密画面上传到尚未确认条款的普通账户。若这些前提不成立，初步技术选择应直接撤回。

## 二、工作流：电商重商品不走样，品牌重已有素材能修改

### 可灵：把商品参考与镜头设计放在生成之前

可灵 3.0 提供图生视频、首尾帧、元素参考和多镜头能力。以 fal 的 Pro 接口为例，可以指定起始图片、引用商品或人物元素，并分别描述镜头及持续时间。这使“先确认商品，再变化镜头”有可操作的入口，而不是每次用一段文字重新想象商品。[可灵功能表](https://kling.ai/quickstart/klingai-video-3-model-user-guide)、[具名接口参数](https://fal.ai/models/fal-ai/kling-video/v3/pro/image-to-video/api)。

对于一条电商新品短片，更合理的试法是保留已获授权的商品主图与包装特写，把生成用在环境、过场和有限运动上。若要展示按键功能、拆装过程或材质性能，应以真实产品和可核对动作验收；无法稳定保真的镜头退回实拍或常规合成。这样选择可灵，不是因为已证明它在所有商品上最准确，而是它的参考输入与镜头控制适合验证这类需求。

语言能力也要跟着入口确认。官方应用指南列有中文、英文、日文、韩文和西班牙文，而上述 fal 接口当前只写明中文及英文原生语音，其他语言会转成英文。做日韩站电商配音时，这一差别足以推翻“直接沿用同一 API”的方案；可以改为单独制作合法授权的配音，或改选明确支持目标语言的服务，但不能把应用宣传当作渠道承诺。[应用语言能力](https://kling.ai/quickstart/klingai-video-3-model-user-guide)、[fal 音频参数](https://fal.ai/models/fal-ai/kling-video/v3/pro/image-to-video/api)。

### Runway：先评估修改现有片子的价值

Runway 的 Aleph 2.0 编辑入口支持对已有视频调整背景、产品外观或光线，产品页列出最长 30 秒、1080p 的序列，并提供先预览参考帧、再应用到视频的流程。对已经拍过主片的品牌团队，这类能力比再生成一段全新镜头更接近日常需求：一次主拍摄之后，还要做季节版、场景版和不同市场的素材变体。[Runway 视频编辑说明](https://runway.com/product/ai-video-editor)。

验收时应把“要求改变的部分”和“不得改变的部分”分别列出。例如背景改为冬季，但商品颜色、人物身份、手部动作和包装字样应保留；只看改后的背景是否好看，会遗漏意外改动。产品页关于精准保持其他部分的描述是能力主张，不能取代逐帧检查。若人工修正非目标区域耗时过长，生成式编辑就未必比既有后期流程节省。

Gen-4.5 则是另一条生成路径，不能与 Aleph 编辑混为一项规格。其 Web 基础输出为 720p；ProRes 或 PNG 序列需要 Max、旧 Unlimited 或 Enterprise 等指定档位，并增加每秒 5 积分，格式在生成时选择。对需要高质量中间文件继续调色、合成的团队，导出权限和费用应在试用时就验证，而不是批准采购后再发现交付格式不匹配。[Gen-4.5 规格和导出要求](https://help.runwayml.com/hc/en-us/articles/46974685288467-Creating-with-Gen-4-5)。

### Veo：音画生成值得比较，但 Flow 的能力不都属于 Veo

Veo 3.1 的 Cloud 文档列有图生视频、首尾帧、声音生成等能力。它适合作为带对白、环境声或动作音效的场景生成候选；如果声画同时可用，理论上能减少分开制作音频的环节，但节省多少必须算上重试、对白修正和后期混音，不能凭原生音频四个字认定成本更低。[Veo 3.1 文档](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/veo/3-1-generate)。

Flow 内还要选对具体版本：其 Veo 3.1 Quality 不支持 Ingredients／References，Lite 可以用于延长符合条件的 Veo 视频；视频到视频编辑则属于其他模型能力，不能因为同在 Flow 界面，就记作 Veo 的编辑优势。这个区别影响品牌工作：需要持续沿用参考素材或延长镜头时，单选名称中的“Quality”未必最适配。Cloud 的模型接口与 Flow 也有不同功能组合，应以所选入口的规格为准。[Flow 型号功能矩阵](https://support.google.com/flow/answer/16352836?hl=en)。

三条路线可以共存，但每增加一个平台，就增加一轮素材传输、权限确认和版本管理。团队应按一个实际项目验证最短可行流程：商品图驱动的短镜头、已有视频的定向修改、需要原生声音的场景，各自只比较真正能完成该任务的候选。把全部功能表放在一起计数，无法回答谁能更省力地交出这条片子。

## 三、成本：先算生成费，再算真正采用的镜头

月费解决的是账户、功能和一定额度的访问；积分是特定平台内的用量单位；API 单价则绑定具体型号、输出参数和渠道。三者不能直接放在一列比较。尤其是会员每月积分有多少、是否过期、某型号每秒扣多少，都会改变实际可用量；“一个月只需几十美元”无法回答一批合格营销素材要花多少钱。

### 一个可复算、但不是质量排名的标价算例

选用同一服务商 fal，输入同一张已获授权的 16:9 图片，生成一段 8 秒、带原生音频的视频，不用语音控制、额外参考元素或多镜头扩展。两条接口均有这些参数的公开说明；可灵 Pro 的 1080p 来自 fal 规格说明，Veo 在接口中显式选择 1080p。[可灵接口](https://fal.ai/models/fal-ai/kling-video/v3/pro/image-to-video/api)、[Pro 规格说明](https://fal.ai/learn/tools/seedance-2-0-vs-kling-3-0)、[Veo 接口](https://fal.ai/models/fal-ai/veo3.1/image-to-video/api)。

| 指定接口与输出 | 公开费率 | 一段 8 秒生成费 |
| --- | --- | --- |
| Kling 3.0 Pro 图生视频，音频开启、无 voice control | 0.168 美元／生成秒 | 1.344 美元 |
| Veo 3.1 图生视频，1080p、音频开启 | 0.40 美元／生成秒 | 3.20 美元 |

计算只是单价乘以 8。价格分别来自 [fal 可灵页](https://fal.ai/models/fal-ai/kling-video/v3/pro/image-to-video) 与 [fal Veo 页](https://fal.ai/models/fal-ai/veo3.1/image-to-video)，不代表可灵直连 API 或 Google Cloud 的合同报价。可灵这条接口没有单独暴露分辨率选项，两端的帧率、压缩和实际视觉质量也未在此得到同一标准验证。因此，它能比较指定入口的名义规格生成费，不能证明输出质量相同，更不是每段广告成片的价格。

这个算例也不是 Veo 全家最低价。Google Developer API 另外公开了 Fast 和 Lite 的较低价格及不同型号；如果需求允许调整速度档、功能和服务入口，应重新比较相应参数，不能用 Standard 代表整个产品家族。可灵直连定价页未提供可读取的当前报价，不能用第三方价替它背书。[Google Developer API 的 Veo 价格](https://ai.google.dev/gemini-api/docs/pricing)、[可灵开发者定价入口](https://kling.ai/dev/pricing)。

Runway API 的 Gen-4.5 是每秒 12 积分，开发者积分为每个 0.01 美元，8 秒生成费据此为 0.96 美元。但其基础输出和音频条件并不与上表一致，不能拿这个更小的数字直接宣布它最便宜；需要的升分辨率、配音、专业格式和后期工作应另算。[Runway API 费率](https://docs.dev.runwayml.com/guides/pricing/)、[Gen-4.5 基础规格](https://help.runwayml.com/hc/en-us/articles/46974685288467-Creating-with-Gen-4-5)。

### 对内容团队，更重要的是采用率和返工

商业上应记录“最终通过验收并实际使用的秒数”，而不是只记录生成成功的秒数。一个透明的成本口径是：

**每个采用秒的成本＝生成、重试、修正、剪辑、音频处理与审核的全部成本 ÷ 实际采用的秒数。**

只看生成费也能说明采用率的重要性。作一个明确的假设：可灵生成秒的采用率为 20%，Veo 为 50%，并暂不计其他成本，则前者为 0.168÷20%＝0.84 美元／采用秒，后者为 0.40÷50%＝0.80 美元／采用秒。便宜的单次生成可能反而有更高的有效成本。这两个采用率纯属说明算式的假设，不是实际测试结果；如果两者采用率相同，表中的相对生成价格当然仍成立。

电商短视频还可能接受从一个片段中截取少量可用画面；品牌整段镜头则可能因一处商品变形或对白错误而整体弃用。两类业务的采用率不能混算。审批修改次数、必须保留的镜头长度和交付时限，应在试用开始时确定，否则团队容易不断放宽验收来证明已购买工具“划算”。

## 四、商用与保密：允许卖成片，不等于允许上传所有原始素材

商业内容需要分别回答三个问题：平台是否允许使用生成物获利；输入的图片、人物、音乐和商标是否有足够授权；平台及其模型供应商可以怎样使用这些输入和输出。第一项通过，不能自动替代后两项。尤其是品牌代运营，客户允许制作广告，并不必然等于允许把未公开资产交给任何生成平台用于训练。

### Runway：普通条款和企业级第三方承诺必须分开

Runway 普通使用条款第 4.4 节没有限制合规用户对输出的商业使用，但同时赋予公司将输入和输出用于训练、改进模型及相关产品的许可。这里说的是条款允许的数据用途，不是断言每一份上传素材都已用于训练。对于只使用自有且已公开素材的探索，这可能是可接受条件；对于客户未发布产品、保密广告脚本或受限代言素材，它足以要求暂停上传，先确认适用协议。[Runway 使用条款，第 4.4 节](https://runway.com/terms-of-use)。

另一方面，Runway 企业 FAQ 明确，企业账户使用第三方模型时适用企业条款和 DPA，并已取得第三方不使用客户内容训练的合同承诺。这是企业采购可以进一步核实的路径，不能倒推出普通 Standard 或 Pro 账户也有同样保障；也不能仅凭一篇第三方模型 FAQ，就替尚未签订的全部模型和全部数据流作统一保证。采购时应拿到适用的订单、DPA、模型清单及访问控制，而不是只保留“可商用”帮助页。[企业级第三方模型政策](https://help.runwayml.com/hc/en-us/articles/51248305153683-Enterprise-FAQ-Third-party-Models-in-Runway)。

### 可灵：会员授权、国际站数据许可与 API 合同各有适用范围

可灵国际站一般条款第 4.6 节对商用要求书面许可，付费会员条款第 3.1.2 节则给出会员输出的商用授权，并有竞品开发等例外。因此，不宜笼统地说“可灵都不能商用”或“可灵都能商用”。购买的是会员、额外积分还是企业 API，适用的权限可能不同；单独购买积分也不自动取得会员权益。[一般条款](https://kling.ai/docs/user-policy)、[会员及积分条款](https://kling.ai/docs/payment-policy)。

国际站一般条款还包含输入、输出及相关内容的使用许可和模型训练用途，并给出通过邮件请求撤回授权的途径。撤回渠道存在，不等于已经验证过去的数据被删除，也不能据此向客户承诺零训练或零保留。[国际站数据许可](https://kling.ai/docs/user-policy)。

与之不同，阿里云市场展示的一份可灵 API 供应合同第 5 节写明不用于训练，第 5.5 节同时写明提示词和响应保留 30 天，第 6.4 节不限制生成物商用。这个差异说明企业应比较具体合同，而不是只比较品牌；该合同不自动覆盖国际站普通用户、fal 或其他转售商。[指定可灵 API 合同](https://market.aliyun.com/product/protocol.htm?code=cmgjllm00073513)。

### Google：Flow 的设置不是 Cloud 的企业合同

Flow 的说明中，启用“帮助改进 Google Flow”时，交互、上传、生成结果等可用于产品与机器学习改进，相关数据可能经过人工审阅；页面直接提醒不要输入不希望审核人员看到的保密信息。企业不能因为账户付过订阅费，就假设它自动具备不训练承诺。关闭产品改进开关也不等于取得与 Cloud 相同的企业合同、责任安排及组织控制。[Flow 数据说明](https://support.google.com/flow/answer/17025472?hl=en)。

Google Cloud 的服务条款则规定，未经客户事先许可或指示，不使用客户数据训练或微调 AI／ML 模型。对符合条件的付费 Cloud 服务，使用正式可用的 Veo 型号也在生成式 AI 赔偿清单中；但输出赔偿涉及未修改输出、输入权利、已知侵权及商标等条件与例外。把生成片段再编辑成品牌广告，尤其应让合同负责人核对具体适用范围，不能把赔偿清单称作“侵权保险”，也不能外推到所有 Preview 或 Flow 消费入口。[Cloud 服务条款](https://cloud.google.com/terms/service-terms)、[赔偿服务清单](https://cloud.google.com/terms/generative-ai-indemnified-services)。

落实到两类业务：电商可以先用权属清楚、无需保密的自有商品素材探索，但最终商品描述和效果必须真实；品牌保密项目则应先确定允许的数据用途、保留期限、处理主体与合同责任，再讨论模型效果。若合适的企业合同显著增加成本，或客户根本不允许相应数据处理，原先“更方便、更便宜”的技术选择就不再成立。

## 五、可靠性与采购：先验证能否按时交片，再扩大使用

现有公开证据不足以支持“某一家能稳定交付商业成片”的结论。Artificial Analysis 的视频比较采用同一提示词下的匿名成对投票，并区分带音频与无音频榜单；它有助于观察观众偏好，却没有直接测量商品细节是否准确、客户改稿能否完成、系统高峰期会不会延迟。排名不能直接换算为广告验收率或生产可用率。[视频评测方法](https://artificialanalysis.ai/video/leaderboard/text-to-video)。

### 画面好看与交付可靠，要分开验收

Runway 自己披露，Gen-4.5 仍有因果顺序、物体持续存在和倾向把动作生成成功等问题。门把手是否先被转动、物品是否意外消失，看似细节，却可能直接使商品功能演示失真。这些公开案例说明应检查什么，不构成与另外两家相比的故障率证据；没有披露同类失败案例的产品，也不能因此被认定更可靠。[Gen-4.5 已知局限](https://runway.com/research/introducing-runway-gen-4.5)。

服务端还存在另一种失败：画面最终能生成，但赶不上项目交期。Runway API 对组织设置用量与并发限制，超过并发额度的任务会进入 THROTTLED 状态，暂未排入处理队列；高负载时实际并发也可能低于上限。文档中的排队例子不是延迟保证。Google Cloud 的 GA 标识同样不能代替企业自己的配额、地区资格和履约条款。需要当天批量交片的团队，应把等待、失败重试和人工接管一并算进生产时间。[Runway API 容量说明](https://docs.dev.runwayml.com/usage/tiers/)、[Veo Cloud 服务规格](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/veo/3-1-generate)。

### 用两类真实项目决定是否采购

电商团队可以选一个包含多个 SKU、包装文字和有限商品动作的短片项目，事先规定哪些画面能截取使用、哪些错误必须整段退回。比较时沿用同一组获授权素材、相同尝试次数与交期，保留失败和弃用结果；若最漂亮的片段恰好改错了商品，它仍然是不合格产出。验收同时记录商品一致性、采用秒数、人工修复时间及全部生成费用，才能判断是否值得加入现有流程。

品牌团队更适合选一段已有主片，提出一次真实修改：例如只换环境与光线，保留人物、商品和镜头运动。对照现有后期方法，记录改稿后仍需修补的非目标区域，以及从发出修改到获得批准的总时间。若生成工具只能提供灵感，却不能按要求局部修改，应按创意预览工具采购，而不是按后期替代方案采购。

两类试用都应先约定退出条件：出现商品功能误导或未经授权的素材处理，停止该用法；反复修补后仍赶不上交期，保留传统制作作为主流程；只有质量达标后，才比较采用成本和扩大量产。样本较少时应公开每次用时和失败原因，不宜把几个成功案例包装成稳定的服务水平。

对于保密项目，合同资格先决定哪些服务能入围；对于交期刚性的项目，人工回退能力决定生成工具能承担多少产量。三家都值得按前述具体任务试用，但目前没有依据把任何一家直接升级为无需复核的成片生产线。
